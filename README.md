# summer_project
summer project to keep myself busy

## Week 1: Setup & Dart Basics
 - Install Flutter & Android Studio/VSCode
 - Run Flutter's demo app on emulator/device
 - Learn Dart basics (variables, loops, functions, classes)
 - Set up Git repo

## Week 2: Flutter UI Basics
- Build a homepage layout (Scaffold, AppBar, BottomNavigationBar)
- Create a simple form with input fields and a save button
- Learn how state works with setState
- Navigate between screens

Deliverable: Mini diary app that saves text fields temporarily in state

## Week 3: Local Storage
- Add SQLite (sqflite) or Hive
- Create a database for period entries
- Store & retrieve logs (date, symptoms, notes)
- Build list view of past entries

Deliverable: Local-only journal of period logs

## Week 4: Cycle Prediction
- Implement average cycle length logic
- Estimate next period and display it
- Build a basic stats screen

Deliverable: Functional tracking & prediction logic

## Week 5: Calendar View & UX Polish
- Add calendar UI (e.g., table_calendar package)
- Show period dates on calendar
- UX polish: dark mode, basic theming
- Add validations (e.g., no future dates)

Deliverable: Visually usable, intuitive tracker

## Week 6: Settings & Data Management
- Add “clear data” and “export to JSON” feature
- Allow local notifications/reminders
- Settings screen with privacy explanation
- Secure the app (biometric lock if ambitious)

Deliverable: Fully local, private period tracking app MVP

## Optional Weeks (7–8): Stretch Goals
- Mood tracking visualisation (graph)
- Custom cycle length tuning
- Gesture navigation
- Accessibility tuning (screen reader, font scaling)

Deliverable: Finished app ready for portfolio or store (if desired)
