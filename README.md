# Tracking times
A truly private period tracking app

## Goal
This project has the goal of becoming a mobile app focused on local usage with data only being stored locally.  
With this project I want to learn more about app development and prediction algorithms.

### Tools
For this project, I use JetBrains' Android Studio with the Gemini 2.5^ Pro as integrated assistant to speed up the development.  
I also use Claude Sonnet 4.6^ to help me with the file structure as I learn.
